About & privacy

Ye page is app ke baare mein plain-language jaankari hai — jo bhi browser ya Google yahan dekh raha ho, usse clear ho jaye ki ye site kya hai aur kya nahi.

Ye app kya hai

Day Matrix Tracker ek chhota personal productivity tool hai. Aap din ko 30-minute slots mein todte ho, har slot mein likhte ho ki kya kiya, aur usko Urgent (Y/N) aur Important (Y/N) mark karte ho. End mein din ko Happy / Not happy mark karte ho.

Overall tab aapke happy dino ka average nikaal ke batata hai ki kaunsa kaam-type aapke achhe dinon mein zyada tha. Ye ek pattern hint hai, guarantee nahi.

Single HTML fileNo loginNo formsNo adsWorks offline

Aapka data kahan jata hai

Kahin nahi. Aapke slots, mood aur notes sirf aapke browser ke localStorage mein save hote hain (key: dmt_v1). Ye data kisi server par nahi jata, kisi third party ko nahi jata, aur mujhe bhi nahi dikhta.

  • Koi account, signup ya password nahi hai.
  • Koi analytics, cookie, tracking pixel ya fingerprinting nahi hai.
  • Koi third-party script, CDN, font ya iframe load nahi hota.
  • Koi file download nahi hota, koi auto-redirect nahi hai.
  • Kuch bhi bank / payment / OTP / ID se related nahi hai — app kabhi koi personal credential maangta hi nahi.

Isi wajah se browser data clear karne par aapka data chala jayega. Help & data tab se backup text nikaal kar sambhal ke rakho.

Kaun banata hai

Banaya Ronit Sundrani ne, ek personal project ke roop mein. Source code public hai: github.com/Ronit2405/Day-matrix-tracker. Wahan aap khud verify kar sakte ho ki page mein sirf HTML, CSS aur ek chhota inline script hai.

Site GitHub Pages par host hoti hai — ronit2405.github.io/Day-matrix-tracker/. GitHub Pages sirf static files serve karta hai; ye app kisi server-side code, database ya user account ka use nahi karta.

Kuch galat lage to

Agar aapke browser ne is site par koi warning dikhayi hai, to bina dar ke Google ko report kar sakte ho, ya GitHub par issue khol sakte ho. Aap source khud padh sakte ho — page mein aisa kuch nahi hai jo aapka data maange ya kisi aur site par bheje.

Page par kya technical restrictions hain

Kisi bhi reviewer ke liye, jo bhi is page ke andar chal sakta hai:

  • Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; script-src 'unsafe-inline'; img-src data:; base-uri 'none'; form-action 'none'
  • Iska matlab: page koi external file load nahi kar sakta, koi request bhej nahi sakta, aur koi form submit nahi kar sakta. Sirf ek inline script aur inline CSS chalta hai.
  • Koi <form> element nahi. Koi password, email, phone, OTP, payment ya card field nahi.
  • Koi geolocation, camera, microphone ya clipboard-read permission nahi maangi jaati. Clipboard sirf tab likha jata hai jab aap khud "Copy" dabate ho.
  • No eval, no atob, no obfuscated code, no redirect, no download.
  • Restore ki gayi backup text aur localStorage data dono validate aur sanitize hote hain — galat shape ka data render nahi hota.
